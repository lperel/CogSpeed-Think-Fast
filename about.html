About CogSpeed®

Read Technical Overview

CogSpeed® is a computer-adaptive, web-based cognitive performance test designed to rapidly and objectively measure aspects of cognitive processing speed and sustained performance ability. It is intended for laboratory research, field studies, repeated self-checking, and readiness screening where alertness and cognitive reliability matter.

CogSpeed is brief, portable, and practical for repeated use. It can run on a smartphone, is designed to be immediately repeatable, and usually takes less than three minutes. Because the task relies on simple visual matching rather than language-heavy content, it can be used across cultures and in many different environments.

Core task
The subject matches a simple visual target as quickly and accurately as possible while presentation pace adapts or remains fixed at a demanding level.
Primary aim
Estimate how rapidly and reliably a person can keep processing under increasing or sustained time pressure.
Best use
Repeated comparisons with the same person’s earlier sessions, and eventually with age- and gender-based population norms when available.

Origins and design logic

CogSpeed grew out of earlier adaptive information-processing work designed to measure performance decline under fatigue and demanding operational conditions. The same basic logic remains: use a brief, repeatable visual task and machine pacing to estimate a person’s fastest reliable cognitive processing performance and how well that performance can be sustained.

CogSpeed emphasizes perception, decision, and response under time pressure rather than vocabulary, language skill, or academic knowledge. It is intended to be portable, economical, practical in laboratory and field settings, and learnable to an individual’s own baseline.

Human factors design features

The core task does not require color vision or hearing. It uses simple visual matching rather than written language, spoken test content, or culture-specific knowledge. The software also includes response-time limits, verification checks, and anomaly-handling logic intended to improve data quality and reduce artifacts from irregular behavior such as random tapping, inattention, spoofing, faking, or other unusual response patterns.

No behavioral test is completely immune to poor effort, unusual responding, or normal moment-to-moment variability. CogSpeed is therefore best understood as a rapid, structured estimate of current performance rather than as a stand-alone diagnostic instrument.

How the test flow works

The app can include saved-profile entry, optional sleep logging, a Samn-Perelli Fatigue Scale rating, and a tutorial. The user then completes the selected test mode. After the test, results can be reviewed in the Speedometer, Results Summary, Trial Detail, graphs, and export tools.

  • Mode 1 CogSpeed Adapted: starts with self-paced calibration and then uses adaptive machine pacing to estimate blocking level under increasing challenge.
  • Mode 2 CogSpeed Sustained: determines an adaptive performance estimate, holds a sustained fixed-rate segment near that level, and ends with final self-paced trials.
  • Mode 3 Self-paced: runs continuous self-paced responding for a fixed period, useful for practice and response-variability work.
  • Mode 4 Machine-paced: uses calibration-derived fixed pacing for a sustained block without adaptive pacing changes.

How to read the main results

Maximum Blocking Speed (MBS) is the pacing-based estimate, in milliseconds, of the presentation rate at which the subject begins to block. Cognitive Processing Index (CPI) is the main normalized 0-100 summary derived from the MBS. Lower CPI and slower MBS generally indicate degraded cognitive performance.

Cognitive Performance Ability (CPA) is a broader Mode 2 sustained-performance estimate derived from CPI plus sustained-phase factors such as correct responses, wrong responses, misses, variability, drift, lapse rate, recovery ratio, and block efficiency. Zero wrongs can help. Zero or very low misses can also help. Moderate error levels can be neutral. Heavier error, miss, or instability patterns can lower the result.

CogSpeed is usually most informative when current results are compared with the subject’s own earlier sessions rather than interpreted as a single isolated number.

Personal baseline and repeated use

CogSpeed is designed to be learned to an individual’s own baseline. After enough qualifying performance has been accumulated, the app can build and store a personal baseline to help place current results in context. Repeated use can help users, researchers, or programs observe decline, recovery, instability, learning effects, sleep-related change, and other trends over time.

Subjective and objective context

Before testing, CogSpeed records the user’s current Samn-Perelli Fatigue Scale (S-PFS) rating. CogSpeed pairs objective task performance with subjective fatigue because self-reported state can add useful context. Subjective decline may appear before larger objective changes become obvious, and repeated use of both measures can help users and researchers understand change over time more clearly.

What CogSpeed may be sensitive to

CogSpeed depends on rapid, sustained cognitive throughput. Therefore, it may be sensitive to fatigue, sleep loss, alcohol, some drugs, reduced alertness, normal aging, dementia, concussion, other brain injuries, and other conditions that slow or destabilize mental performance. However, CogSpeed does not by itself identify the cause of reduced performance.

Uses

Personal use: repeated self-checks, trend monitoring over days and months, sleep-and-fatigue tracking, readiness checks before demanding activity, and review of baseline changes over time.

Research use: fatigue studies, sleep-deprivation and circadian-rhythm work, work-rest-cycle studies, psychopharmacology, alcohol studies, traumatic brain injury research, aging and dementia comparisons, individual-differences work, and synchronized comparison with electroencephalography, functional magnetic resonance imaging, brain-scan, or artificial-intelligence analysis pipelines.

Fit-for-duty and operational use: preliminary readiness screening in settings where alertness and cognitive reliability matter, such as transportation, aviation, energy, industrial operations, emergency response, and other hazardous environments. CogSpeed is intended to support structured human review, not replace it.

Additional challenge tests

CogSpeed also includes supplementary challenge formats that preserve the same core scoring framework while using different symbol sets. The CogSpeed Memory Challenge increases memory demand and may be useful for studying learning effects. The CogSpeed Survival Challenge uses a combat-themed icon set to increase engagement and encourage maximum effort. These supplementary formats do not replace the program’s main focus on Mode 2 CogSpeed Sustained.

Audio playback notes

The Survival Challenge and the Scheduler reminder use the device’s standard audio output. On iOS and iPadOS, web audio uses an “ambient” session category by default: this means CogSpeed sounds mix with background music but are also ducked or interrupted by incoming calls, Siri, and other priority system audio. For the most reliable sound during testing, close other audio apps before starting a session, set the device volume before the test, and keep the ringer switch unmuted. If a scheduler reminder sound is missed while another app held audio focus, CogSpeed will still show the on-screen prompt and (if enabled) the voice prompt.

Privacy and deployment posture

The app stores its working data locally on the device and is designed to function offline after installation. Profiles, scheduler settings, results history, sleep entries, and review pages are intended to support practical repeated use without requiring constant network access. Geolocation can record where a test was taken when location capture is available and permitted.

CogSpeed is free to use for personal or research purposes. It contains no ads, and data is not sold to or shared with unauthorized parties. Data remains on the user’s device unless the user gives explicit permission for it to be used for research purposes. Future research download features should require clear positive opt-in and appropriate informed consent.
