About CogSpeed®

CogSpeed is a brief cognitive performance test designed to measure how rapidly a person can identify a simple visual pattern, match it correctly, and continue performing as time pressure increases. The task emphasizes processing speed and sustained performance rather than reading, language skill, or memorization.

Core task
The center probe shows dots or lines. The subject finds the matching pattern above and taps the response gear in the same position below.
Primary aim
Estimate how well the subject can keep up accurately as presentation pace tightens or stabilizes at a challenging rate.
Best use
Repeated self-monitoring, longitudinal tracking, research, field use, and readiness screening with appropriate oversight.

Origins and design logic

CogSpeed grew out of earlier adaptive information-processing work developed to measure performance decline under fatigue and demanding operational conditions. The same core logic remains: use a brief, repeatable visual task and adaptive machine pacing to estimate a person’s fastest reliable cognitive processing performance.

Rather than trying to measure knowledge, vocabulary, or memory, CogSpeed focuses on how quickly and accurately the subject can perceive, decide, and respond under sustained demand. The task is intended to be portable, repeatable, practical in the laboratory or field, and broadly usable across cultures because it relies on simple visual matching rather than language-heavy content.

How CogSpeed adapts

When enough time is available, the matching rule is simple. As the pace becomes more demanding, results increasingly reflect the subject’s ability to keep processing correctly and consistently. The adaptive logic is designed to hunt for the fastest presentation rate the subject can reliably manage, while also checking for misses, instability, and other signs that the apparent speed may not represent true sustained performance.

How the test flow works

The app can include saved-profile entry, optional sleep logging, a Samn-Perelli Fatigue Scale rating, and a seven-page tutorial with direct Skip to Test access from every page. After the selected mode is completed, the result can be reviewed in the Speedometer, Results Summary, Trial Detail, graphs, and export tools.

  • Mode 1 CogSpeed Adapted: starts with calibration and then uses adaptive machine pacing to estimate blocking level under increasing challenge.
  • Mode 2 CogSpeed Sustained: reaches an adaptive level, holds a sustained fixed-rate segment there, and finishes with true self-paced final trials.
  • Mode 3 Self-paced: allows rapid repeated responding without machine pacing, useful for practice or alternate tracking needs.
  • Mode 4 Machine-paced: uses a calibration-derived fixed pace for a sustained presentation block without adaptive pacing changes.

Workflow and reporting features

  • Personal Baseline: the Speedometer includes an in-app Personal Baseline page that summarizes recent qualifying sessions and helps place a current result in context.
  • Mode 2 result views: Mode 2 results can be viewed as Cognitive Processing Index (CPI) and Maximum Blocking Speed (MBS), or as Cognitive Performance Ability (CPA) and Disposition, making it easier to compare speed, stability, and sustained performance quality.
  • Profile Scheduler: Registered users can select a local on-device scheduler with Anytime, Personal, and Fit-for-Duty reminder options, including sound and voice alerts.
  • Sleep and fatigue context: optional sleep logging and the Samn-Perelli Fatigue Scale can be saved with each session to improve interpretation of trends over date and time.
  • In-app review: the app includes Speedometer, Results Summary, Trial Detail, response graphs, and performance-over-time graphing without requiring an external dashboard.
  • Offline-oriented packaging: the app is designed as a progressive web app with local storage and service-worker support so it remains practical in field or low-connectivity use.

How to read the main results

Cognitive Processing Index (CPI) is the main normalized 0-100 summary of processing performance. Maximum Blocking Speed (MBS) is the pacing-based estimate, in milliseconds, of the presentation rate at which the subject begins to block. Higher CPI and faster sustainable MBS generally indicate better performance.

Cognitive Performance Ability (CPA) is a broader Mode 2 sustained-performance estimate derived from CPI plus sustained-phase factors such as correct responses, wrongs, misses, variability, drift, lapse rate, recovery ratio, and block efficiency. Zero wrongs can help, zero or very low misses can help, moderate error levels can be neutral, and heavier error or instability patterns can lower the result.

CogSpeed is usually most informative when current results are compared with the subject’s own earlier sessions rather than interpreted as a single isolated number.

Subjective and objective context

CogSpeed pairs objective task performance with the Samn-Perelli Fatigue Scale because self-reported state can add useful context. Subjective decline can appear before larger objective changes are obvious, and repeated use of both measures can help users, researchers, or programs follow trends over time more clearly.

What CogSpeed may be sensitive to

CogSpeed depends on rapid, sustained cognitive throughput. Therefore, it may be sensitive to fatigue, sleep loss, alcohol, some drugs, reduced alertness, normal aging effects, dementia, concussion, other brain injuries, and other conditions that slow or destabilize mental performance. However, CogSpeed does not by itself identify the cause of reduced performance.

Objectivity and anomaly detection

CogSpeed is intended as an objective behavioral screen, but no behavioral test is completely immune to poor effort or unusual response patterns. The app therefore uses timing rules, error limits, repeatability checks, and anomaly-handling logic to reduce artifacts from random tapping, inattention, or other irregular behavior. It is best understood as a rapid, structured estimate of current performance rather than as an all-knowing diagnostic instrument.

Personal, research, and fit-for-duty uses

Personal use: repeated self-checks, trend monitoring over days and months, sleep-and-fatigue tracking, readiness checks before demanding activity, and review of baseline changes over time.

Research use: laboratory fatigue studies, sleep-deprivation and circadian-rhythm work, work-rest-cycle studies, psychopharmacology, alcohol studies, traumatic brain injury research, aging and dementia comparisons, individual-differences work, and synchronized comparison with electroencephalography, functional magnetic resonance imaging, brain-scan, or artificial-intelligence analysis pipelines.

Fit-for-duty and operational use: preliminary readiness screening in settings where alertness and cognitive reliability matter, such as transportation, aviation, energy, industrial operations, emergency response, and other hazardous environments. CogSpeed is intended to support structured human review, not replace it.

Privacy and deployment posture

The app stores its working data locally on the device and is designed to function offline after installation. Profiles, scheduler settings, results history, sleep entries, and review pages are intended to support practical repeated use without requiring constant network access. Deployment-specific policies, backups, exports, and retention should still be governed by the organization or study using the app.

Additional Challenge Tests

CogSpeed also includes optional challenge formats that use alternative symbol sets while preserving the same core CogSpeed scoring framework. These include the CogSpeed Memory Challenge and CogSpeed Survival Challenge. These challenge tests are supplementary formats only. The main focus of this program remains CogSpeed Sustained - Mode 2.

The CogSpeed Memory Challenge uses learned icon-pair matching instead of the original dot-and-line patterns. The subject must recognize the paired match for the center probe icon, find that matching icon in the gears above, and then tap the response gear in the same position below. This test is has higher memory requirements and is difficult to learn.

The CogSpeed Survival Challenge uses a survival/combat-themed icon set with the same paired-match rule and the same position-based response method. It preserves the CogSpeed test structure while changing the symbol set and challenge style. The intent is to add incentive to encourage the user to try their hardest to score as high as possible.

Both challenge tests are intended as additional formats built on the CogSpeed system. They do not replace the primary role of CogSpeed Sustained - Mode 2, which remains the central focus of the program.
